# Search engine notes

Google search access (google.com/search) was persistently blocked in this
environment with a reCAPTCHA "unusual traffic from your computer network"
wall on every attempt (direct URL navigation, search-box interaction,
multiple query phrasings, across a fresh session). The reCAPTCHA requires
solving an image challenge that cannot be reliably completed here, and the
block did not clear after multiple retries. Bing and DuckDuckGo were used
as fallback web search engines to accomplish the task's actual goal
(identifying each sorority's official chapter website and sisters/member
roster pages), since Google itself was categorically inaccessible for
automated queries in this session.

This note documents the substitution for transparency.
